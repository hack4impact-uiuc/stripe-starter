# Next.js Stripe Starter

1. `npm install`
2. `cp .env.example .env.local` and paste your Stripe **test** secret key
3. `npm run dev` → open http://localhost:3000

Click **Buy iPhone Duo** and pay with test card `4242 4242 4242 4242`, any future date, any CVC.
